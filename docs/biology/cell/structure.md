# 细胞的结构与功能

## 1. 细胞学说

细胞是生物体结构和功能的基本单位。

## 2. 细胞膜

流动镶嵌模型：磷脂双分子层为基本支架，蛋白质分子镶嵌或贯穿其中。

功能：分隔、物质交换、信息交流。

## 3. 细胞器

| 细胞器 | 主要功能 |
|--------|----------|
| 线粒体 | 有氧呼吸主要场所 |
| 叶绿体 | 光合作用场所 |
| 内质网 | 蛋白质等加工运输 |
| 高尔基体 | 加工、分类、包装 |
| 核糖体 | 蛋白质合成 |
| 溶酶体 | 消化分解 |
| 液泡 | 调节渗透压（植物） |

## 4. 细胞核

遗传信息库，控制细胞代谢和遗传。核膜、核仁、染色质。
