# 化学平衡

## 1. 平衡状态

正反应速率等于逆反应速率，各组分浓度保持不变（动态平衡）。

---

## 2. 平衡常数

对于 $aA + bB \rightleftharpoons cC + dD$：

$$K = \dfrac{[C]^c [D]^d}{[A]^a [B]^b}$$

$K$ 只与温度有关。

---

## 3. 勒夏特列原理

如果改变影响平衡的一个条件，平衡就向能够减弱这种改变的方向移动。

- 增大反应物浓度 → 正向移动
- 升高温度 → 向吸热方向移动
- 增大压强 → 向气体体积减小的方向移动
