# 常见实词与虚词

## 1. 高频实词（举例）

| 词 | 常见义项 | 例句方向 |
|----|----------|----------|
| 绝 | 断绝；横渡；极 | 假舟楫者，非能水也，而绝江河 |
| 胜 | 禁得起；尽；胜利 | 跨者无可奈何，而不能胜 |
| 因 | 于是；凭借；顺着 | 因利乘便，宰割天下 |
| 属 | 连接；嘱托；类 | 属予作文以记之 |
| 谢 | 道歉；推辞；凋落 | 阿母谢媒人 |

记忆提示：**结合语境判断义项**，不要只背一个意思。

## 2. 常见虚词

- **而**：并列 / 转折 / 修饰 / 承接
- **以**：凭借 / 目的 / 原因 / 把
- **于**：在、到、对、比、被
- **其**：代词；语气（难道、还是）
- **之**：代词；取消句子独立性；到往

## 3. 方法

1. 先通读，标出难以理解的词  
2. 用「代入检验」看哪个义项更通顺  
3. 注意古今异义（如「交通」「妻子」「绝境」）
