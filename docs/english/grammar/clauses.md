# 从句

## 1. 定语从句

修饰名词或代词。关系词：who, whom, whose, which, that, when, where, why。

限制性与非限制性定语从句的区别需注意。

## 2. 名词性从句

主语从句、宾语从句、表语从句、同位语从句。

连接词：that, whether/if, who, what, where, when, why, how 等。

## 3. 状语从句

时间、地点、原因、结果、条件、目的、让步、比较、方式等。

常见引导词：when, while, because, if, although, so that 等。
