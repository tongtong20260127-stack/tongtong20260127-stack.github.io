# 虚拟语气与倒装

## 1. 虚拟语气

表示与事实相反或难以实现的情况。

- 与现在事实相反：If + 过去式，would/could + do
- 与过去事实相反：If + had done，would/could + have done
- 与将来事实相反：If + should/were to do，would + do

其他：wish, as if, suggest/insist 等后的虚拟。

## 2. 倒装

- 完全倒装：副词开头（here, there, up, down 等）+ 谓语 + 主语
- 部分倒装：否定词开头（never, hardly, not only 等）+ 助动词 + 主语 + 动词
