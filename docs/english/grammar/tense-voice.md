# 时态与语态

## 1. 主要时态

| 时态 | 结构 | 用法 |
|------|------|------|
| 一般现在时 | do/does | 习惯、真理、现在状态 |
| 一般过去时 | did | 过去发生的动作或状态 |
| 一般将来时 | will do / be going to | 将来动作或打算 |
| 现在进行时 | be doing | 正在进行 |
| 现在完成时 | have/has done | 过去发生并对现在有影响 |
| 过去完成时 | had done | 过去的过去 |

## 2. 被动语态

结构：be + 过去分词。时态变化体现在 be 动词上。

适用：不知道或不必说出动作执行者，或强调动作承受者。
