# 词根、词缀与构词法

## 常见前缀

| 前缀 | 含义 | 例词 |
|------|------|------|
| un-/in-/im-/il-/ir- | 不、否定 | unhappy, impossible |
| re- | 再次 | rewrite, return |
| pre- | 在前 | preview, prepare |
| dis- | 否定、相反 | disappear, dislike |

## 常见后缀

| 后缀 | 词性 | 例词 |
|------|------|------|
| -tion/-sion | 名词 | education, decision |
| -able/-ible | 形容词 | comfortable, possible |
| -ly | 副词 | quickly, carefully |
| -ful/-less | 形容词 | useful, hopeless |

掌握构词法可大幅提升词汇量与猜词能力。
