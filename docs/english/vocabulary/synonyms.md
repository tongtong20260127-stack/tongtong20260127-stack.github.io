# 同义词与近义词辨析

英语中许多词意思相近但用法、语气、搭配不同。

## 示例

- **big / large / great**：big 口语常用；large 强调面积/数量；great 强调程度或重要性
- **say / speak / talk / tell**：say 侧重内容；speak 侧重能力或语言；talk 强调交流；tell 后接人
- **look / see / watch**：look 强调动作；see 强调结果；watch 强调持续关注

学习时注意搭配与语境差异。
