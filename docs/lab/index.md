# 物理 / 化学实验

在这里可以**模拟**中学常见的化学与物理实验：从左侧拖器材/试剂到实验台，进行倾倒、混合、加热、接线等操作。

| 实验室 | 说明 |
|--------|------|
| [化学实验台](chemistry.md) | 器材 + 试剂拖放，混合/倾倒，实时分子式与离子方程式 |
| [物理实验台](physics.md) | 简易电路：电源、开关、灯泡、电阻，观察通断与电流估算 |

!!! tip "保存进度"
    **登录后**可在实验页将当前台面状态保存到云端，换设备也能继续。

!!! note "说明"
    本模拟用于理解原理与现象，反应库覆盖常见中学反应，并非完整热力学/动力学引擎。
