# 函数与方程

## 1. 函数的基本概念

函数是两个非空数集之间的对应关系：对于集合 $A$ 中的每一个 $x$，在集合 $B$ 中都有唯一确定的 $y$ 与之对应。

- **定义域**：使函数有意义的 $x$ 的取值范围
- **值域**：函数值 $y$ 的取值范围
- **对应法则**：核心，决定函数的本质

### 常见函数类型

| 类型 | 表达式 | 图像特征 |
|------|--------|----------|
| 一次函数 | $y = kx + b$ | 直线 |
| 二次函数 | $y = ax^2 + bx + c$ | 抛物线 |
| 幂函数 | $y = x^\alpha$ | 取决于 $\alpha$ |
| 指数函数 | $y = a^x\ (a>0,a\neq1)$ | 过 $(0,1)$，单调 |
| 对数函数 | $y = \log_a x$ | 过 $(1,0)$，与指数互逆 |
| 三角函数 | $\sin x,\cos x,\tan x$ | 周期函数 |

---

## 2. 函数的性质

### 单调性

在区间 $I$ 上，若 $x_1 < x_2$ 时恒有 $f(x_1) < f(x_2)$（或 $>$），则称 $f$ 在 $I$ 上单调递增（减）。

判断方法：定义法、导数法、复合函数单调性。

### 奇偶性

- 奇函数：$f(-x) = -f(x)$，图像关于原点对称
- 偶函数：$f(-x) = f(x)$，图像关于 $y$ 轴对称

### 周期性

存在常数 $T \neq 0$，使得 $f(x+T) = f(x)$ 对定义域内所有 $x$ 成立，$T$ 为周期。

---

## 3. 方程

### 一元二次方程

$$ax^2 + bx + c = 0\ (a\neq0)$$

- 判别式 $\Delta = b^2 - 4ac$
- 求根公式 $x = \dfrac{-b \pm \sqrt{\Delta}}{2a}$
- 韦达定理：$x_1 + x_2 = -\dfrac{b}{a}$，$x_1 x_2 = \dfrac{c}{a}$

### 高次方程与分式方程

常用方法：因式分解、换元法、数形结合。

---

## 4. 重要思想

- **数形结合**：通过图像研究函数性质与方程根的分布
- **分类讨论**：含参问题的核心
- **转化与化归**：复杂问题转化为熟悉的基本函数或方程
