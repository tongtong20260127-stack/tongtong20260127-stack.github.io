# 数列

## 1. 基本概念

数列是按一定顺序排列的一列数，记为 $\{a_n\}$。

- **通项公式**：写出第 $n$ 项 $a_n$ 的表达式
- **递推公式**：由前面的项确定后面的项
- **前 $n$ 项和**：$S_n = a_1 + a_2 + \cdots + a_n$

关系：$a_n = S_n - S_{n-1}\ (n\geq2)$，$a_1 = S_1$。

---

## 2. 等差数列

定义：从第二项起，每一项与前一项的差为常数 $d$（公差）。

- 通项：$a_n = a_1 + (n-1)d$
- 前 $n$ 项和：$S_n = \dfrac{n(a_1 + a_n)}{2} = na_1 + \dfrac{n(n-1)}{2}d$
- 重要性质：$a_m + a_n = a_p + a_q$（当 $m+n = p+q$）

---

## 3. 等比数列

定义：从第二项起，每一项与前一项的比为常数 $q$（公比）。

- 通项：$a_n = a_1 q^{n-1}$
- 前 $n$ 项和：
  - $q \neq 1$ 时：$S_n = a_1 \dfrac{1-q^n}{1-q}$
  - $q = 1$ 时：$S_n = n a_1$
- 重要性质：$a_m \cdot a_n = a_p \cdot a_q$（当 $m+n = p+q$）

---

## 4. 常见求和方法

1. 公式法（等差、等比）
2. 裂项相消
3. 错位相减
4. 分组求和
5. 倒序相加

---

## 5. 递推数列初步

常见类型：
- $a_{n+1} = a_n + f(n)$ → 累加
- $a_{n+1} = k a_n + f(n)$ → 构造等比或迭代
- $a_{n+1} = \dfrac{a_n}{1 + a_n}$ 等 → 取倒数转化
