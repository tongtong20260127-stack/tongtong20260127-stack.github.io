# 圆锥曲线 Conic Sections

> 圆锥曲线是用平面去截圆锥面得到的曲线，高中数学的核心内容之一。

圆锥曲线主要包括 **椭圆**、**双曲线** 和 **抛物线**。它们都可以通过统一的定义（到定点与定直线的距离之比等于离心率）来刻画。

## 统一定义

平面内到定点 $F$（焦点）的距离与到定直线 $l$（准线）的距离之比等于常数 $e$（离心率）的点的轨迹：

- 当 $0 < e < 1$ 时，轨迹为 **椭圆**
- 当 $e > 1$ 时，轨迹为 **双曲线**
- 当 $e = 1$ 时，轨迹为 **抛物线**

## 学习建议

1. **先掌握定义与标准方程**，能快速判断曲线类型与基本量（$a,b,c,e$）。
2. **深刻理解几何性质**（焦点、准线、离心率、渐近线等）。
3. **熟练运用二级结论**，提高解题速度与准确率。
4. **多画图**，数形结合是圆锥曲线的灵魂。
