# 圆锥曲线二级结论汇总

> 二级结论是提高解题速度的关键武器。理解推导过程后记忆，效果最佳。

---

## 一、椭圆常用二级结论

### 1. 焦点弦相关

设椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$，过焦点 $F$ 的弦 $AB$。

- **弦长公式**：
  $$|AB| = \dfrac{2ab^2}{a^2 - c^2 \cos^2 \theta} \quad (\theta \text{ 为弦与 } x \text{ 轴夹角})$$
  或用焦半径：
  $$|AB| = |AF| + |BF|$$

- **通径长**：$\dfrac{2b^2}{a}$（最短焦点弦）

### 2. 中点弦公式

设弦 $AB$ 中点为 $M(x_0, y_0)$，则弦所在直线方程为：

$$\dfrac{x_0 x}{a^2} + \dfrac{y_0 y}{b^2} = \dfrac{x_0^2}{a^2} + \dfrac{y_0^2}{b^2}$$

（点差法得出）

### 3. 焦半径

$$|PF_1| = a + e x_0,\quad |PF_2| = a - e x_0$$

### 4. 离心率范围常见题型

- 椭圆内接三角形、四边形最值问题常与 $e$ 相关
- 焦点三角形面积 $S = b^2 \tan \dfrac{\theta}{2}$ 等（$	heta$ 为焦点张角）

## 二、双曲线常用二级结论

### 1. 渐近线相关

- 双曲线上任意一点到两条渐近线的距离之积为常数 $\dfrac{a^2 b^2}{c^2}$
- 与渐近线平行的直线与双曲线最多有一个交点

### 2. 焦点弦

通径长仍为 $\dfrac{2b^2}{a}$。

### 3. 中点弦公式

与椭圆类似（符号改变）：

$$\dfrac{x_0 x}{a^2} - \dfrac{y_0 y}{b^2} = \dfrac{x_0^2}{a^2} - \dfrac{y_0^2}{b^2}$$

### 4. 等轴双曲线

$a = b$ 时，$e = \sqrt{2}$，渐近线垂直，有很多优美性质。

## 三、抛物线常用二级结论

### 1. 焦点弦弦长

$$|AB| = x_1 + x_2 + p = \dfrac{2p}{\sin^2 \theta}$$

### 2. 通径

通径长 $2p$，是最短的焦点弦。

### 3. 焦点弦的一个重要性质

设 $AB$ 过焦点 $F$，则：

$$\dfrac{1}{|AF|} + \dfrac{1}{|BF|} = \dfrac{2}{p}$$

### 4. 中点坐标

若 $AB$ 是抛物线 $y^2 = 2px$ 的焦点弦，中点 $M(x_0, y_0)$，则：

$$y_0^2 = 2p\left(x_0 - \dfrac{p}{2}\right)$$

（即中点在以焦点为顶点、开口相同的“半通径”抛物线上）

### 5. 参数 $t$ 的应用

若 $A(t_1)$、$B(t_2)$，则：

- 弦 $AB$ 的斜率 $k = \dfrac{2}{t_1 + t_2}$
- 若过焦点，则 $t_1 t_2 = -1$

---

## 四、通用方法与技巧

1. **点差法**：求中点弦、弦的斜率最常用。
2. **焦半径公式**：涉及焦点距离时优先使用。
3. **参数方程 / 离心角**：求最值、面积时经常用到。
4. **联立方程 + 韦达定理**：处理直线与圆锥曲线相交问题的基本方法。
5. **数形结合**：画图永远是第一选择。

---

## 五、记忆口诀（简要）

- 椭圆：$a^2 - b^2 = c^2$，$e < 1$
- 双曲线：$a^2 + b^2 = c^2$，$e > 1$，牢记渐近线
- 抛物线：$e = 1$，焦准距离相等，$p$ 是关键
