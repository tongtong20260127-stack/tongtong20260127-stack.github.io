# 解析几何

解析几何用代数方法研究几何问题，核心是坐标系与方程。

## 1. 直线

### 方程形式

- 点斜式：$y - y_0 = k(x - x_0)$
- 斜截式：$y = kx + b$
- 两点式：$\dfrac{y - y_1}{y_2 - y_1} = \dfrac{x - x_1}{x_2 - x_1}$
- 一般式：$Ax + By + C = 0$

### 距离公式

点到直线距离：

$$d = \dfrac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$

两平行线距离：

$$d = \dfrac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$$

## 2. 圆

标准方程：$(x - a)^2 + (y - b)^2 = r^2$

一般方程：$x^2 + y^2 + Dx + Ey + F = 0$

直线与圆的位置关系：比较圆心到直线的距离与半径。
