# 平面几何

## 1. 三角形

### 基本定理

- **正弦定理**：$\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R$
- **余弦定理**：$c^2 = a^2 + b^2 - 2ab\cos C$
- **面积公式**：$S = \dfrac{1}{2}ab\sin C = \sqrt{p(p-a)(p-b)(p-c)}$（海伦公式）

### 重要心

| 名称 | 定义 | 性质 |
|------|------|------|
| 重心 | 三中线交点 | 分中线为 $2:1$ |
| 内心 | 三内角平分线交点 | 内切圆圆心 |
| 外心 | 三边垂直平分线交点 | 外接圆圆心 |
| 垂心 | 三高交点 | — |

## 2. 圆

- 圆周角定理：同弧所对圆周角等于圆心角的一半
- 弦切角定理：弦切角等于它所夹弧对的圆周角
- 相交弦定理、切割线定理、切线长定理
