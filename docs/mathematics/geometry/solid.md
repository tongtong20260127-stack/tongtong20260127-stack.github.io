# 立体几何

## 1. 空间几何体

### 棱柱、棱锥、棱台

- 棱柱：侧棱平行，两底面平行
- 棱锥：顶点与底面多边形
- 棱台：棱锥被平行于底面的平面所截

### 圆柱、圆锥、圆台、球

体积与表面积公式需熟练记忆。

**球的体积与表面积**：

$$V = \dfrac{4}{3}\pi R^3,\quad S = 4\pi R^2$$

---

## 2. 空间点、线、面位置关系

### 直线与平面

- 平行：线面平行判定（线线平行 → 线面平行）
- 垂直：线面垂直判定（线垂直平面内两条相交直线）

### 平面与平面

- 平行：面面平行判定（一个平面内两条相交直线平行于另一个平面）
- 垂直：面面垂直判定（一个平面过另一个平面的垂线）

---

## 3. 空间向量与坐标

用空间向量处理平行、垂直、夹角、距离问题，计算量相对可控。

夹角余弦：

$$\cos \theta = \dfrac{\vec{a} \cdot \vec{b}}{|\vec{a}| |\vec{b}|}$$

点到平面距离：

$$d = \dfrac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}$$
