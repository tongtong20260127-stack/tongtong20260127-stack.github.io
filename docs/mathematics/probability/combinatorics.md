# 排列组合

## 1. 基本原理

- **分类加法原理**：完成一件事有 $n$ 类方法，第 $i$ 类有 $m_i$ 种，则总方法数 $m_1 + m_2 + \cdots + m_n$
- **分步乘法原理**：完成一件事需 $n$ 个步骤，第 $i$ 步有 $m_i$ 种，则总方法数 $m_1 \times m_2 \times \cdots \times m_n$

---

## 2. 排列

从 $n$ 个不同元素中取 $k$ 个按顺序排列：

$$A_n^k = n(n-1)\cdots(n-k+1) = \dfrac{n!}{(n-k)!}$$

全排列：$A_n^n = n!$

---

## 3. 组合

从 $n$ 个不同元素中取 $k$ 个（无序）：

$$C_n^k = \dfrac{A_n^k}{k!} = \dfrac{n!}{k!(n-k)!}$$

性质：$C_n^k = C_n^{n-k}$，$C_n^k + C_n^{k-1} = C_{n+1}^k$

---

## 4. 常用技巧

- 捆绑法（相邻问题）
- 插空法（不相邻问题）
- 隔板法（正整数解问题）
- 间接法（排除法）
