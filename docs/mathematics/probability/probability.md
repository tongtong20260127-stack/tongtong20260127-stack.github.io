# 概率

## 1. 随机事件与概率

- 必然事件概率为 1，不可能事件概率为 0
- 概率满足非负、归一、可列可加

### 古典概型

样本空间有限且等可能：

$$P(A) = \dfrac{|A|}{|\Omega|}$$

### 几何概型

用长度、面积、体积度量：

$$P(A) = \dfrac{\text{构成事件 } A \text{ 的区域量}}{\text{试验全部结果对应的区域量}}$$

---

## 2. 概率公式

- 对立事件：$P(\bar{A}) = 1 - P(A)$
- 加法公式：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$
- 条件概率：$P(A|B) = \dfrac{P(A \cap B)}{P(B)}$
- 乘法公式：$P(A \cap B) = P(B) P(A|B)$
- 全概率公式与贝叶斯公式

---

## 3. 独立性

事件 $A,B$ 独立 $\Leftrightarrow$ $P(A \cap B) = P(A)P(B)$

独立与互斥要严格区分。

---

## 4. 离散型随机变量

- 分布列、期望 $E(X) = \sum x_i p_i$
- 方差 $D(X) = E(X^2) - [E(X)]^2$
- 常见分布：两点分布、二项分布、超几何分布
