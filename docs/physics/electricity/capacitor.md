# 电容器

## 1. 电容

$$C = \dfrac{Q}{U}$$

平行板电容器：$C = \dfrac{\varepsilon S}{4\pi k d}$（或 $C = \dfrac{\varepsilon_r \varepsilon_0 S}{d}$）

---

## 2. 充放电

- 充电：极板带电量增加，电压升高
- 放电：极板带电量减少

### 常见动态分析

电容器与电源连接（$U$ 不变）或充电后断开（$Q$ 不变）时，改变 $d$、$S$ 对 $C$、$E$、$Q$ 等的影响。

---

## 3. 电容器的能量

$$E = \dfrac{1}{2}CU^2 = \dfrac{Q^2}{2C} = \dfrac{1}{2}QU$$
