# 恒定电流

## 1. 电流

$$I = \dfrac{Q}{t}$$

微观表达式：$I = nqvs$（$n$ 为自由电荷数密度，$s$ 为横截面积）

---

## 2. 欧姆定律

$$I = \dfrac{U}{R}$$

电阻定律：$R = \rho \dfrac{l}{S}$

---

## 3. 电功与电热

电功：$W = UIt = I^2 Rt = \dfrac{U^2}{R}t$（纯电阻电路）

电热（焦耳定律）：$Q = I^2 Rt$

---

## 4. 串并联

- 串联：电流相等，电压分配与电阻成正比，总阻 $R = R_1 + R_2 + \cdots$
- 并联：电压相等，电流分配与电阻成反比，总阻 $\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \cdots$
