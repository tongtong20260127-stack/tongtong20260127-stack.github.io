# 静电场与电势

## 1. 库仑定律

$$F = k\dfrac{q_1 q_2}{r^2}$$

$k = 9.0 \times 10^9\ \mathrm{N\cdot m^2/C^2}$

---

## 2. 电场强度

$$\vec{E} = \dfrac{\vec{F}}{q}$$

点电荷电场：$E = k\dfrac{Q}{r^2}$

电场线：从正电荷或无穷远出发，终止于负电荷或无穷远；疏密表示强弱。

---

## 3. 电势与电势差

电势 $\varphi$ 是标量，电势差 $U_{AB} = \varphi_A - \varphi_B$。

电场力做功与路径无关：$W_{AB} = qU_{AB}$

电势能 $E_p = q\varphi$

---

## 4. 等势面

等势面上电势相等，电场线与等势面垂直。
