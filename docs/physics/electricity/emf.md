# 电动势与闭合电路欧姆定律

## 1. 电动势

电动势 $E$ 等于非静电力把单位正电荷在电源内从负极移到正极所做的功。

---

## 2. 闭合电路欧姆定律

$$I = \dfrac{E}{R + r}$$

其中 $r$ 为电源内阻，$R$ 为外电阻。

路端电压 $U = E - Ir = IR$

---

## 3. 常见结论

- 外电阻增大 → 电流减小 → 路端电压增大
- 短路时 $I = \dfrac{E}{r}$，路端电压为 0
- 断路时电流为 0，路端电压等于电动势
