# 圆周运动与万有引力

## 1. 圆周运动

### 描述物理量

- 线速度 $v$、角速度 $\omega$、周期 $T$、频率 $f$
- 关系：$v = \omega r$，$\omega = \dfrac{2\pi}{T}$，$f = \dfrac{1}{T}$

### 向心加速度与向心力

$$a_n = \dfrac{v^2}{r} = \omega^2 r$$

$$F_n = m\dfrac{v^2}{r} = m\omega^2 r$$

向心力由合力提供，不是一种新的力。

---

## 2. 万有引力定律

$$F = G\dfrac{m_1 m_2}{r^2}$$

### 天体运动

把圆周运动向心力由万有引力提供：

$$G\dfrac{Mm}{r^2} = m\dfrac{v^2}{r} = m\omega^2 r = m\dfrac{4\pi^2}{T^2}r$$

可推导第一、第二、第三宇宙速度等。

### 开普勒三定律（简述）

1. 轨道是椭圆，太阳在一个焦点上
2. 面积速度恒定
3. $\dfrac{T^2}{a^3} = k$（对同一中心天体）
