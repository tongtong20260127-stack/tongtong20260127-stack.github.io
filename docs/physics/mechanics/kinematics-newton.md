# 运动学与牛顿运动定律

## 1. 运动学基础

### 描述运动的物理量

- 位移 $\vec{x}$、速度 $\vec{v}$、加速度 $\vec{a}$
- 平均速度与瞬时速度
- 匀变速直线运动公式：

$$v = v_0 + at$$
$$x = v_0 t + \dfrac{1}{2}at^2$$
$$v^2 - v_0^2 = 2ax$$

### 运动图像

- $x$-$t$ 图像：斜率表示速度
- $v$-$t$ 图像：斜率表示加速度，面积表示位移

---

## 2. 牛顿运动定律

### 第一定律（惯性定律）

物体保持匀速直线运动或静止状态，直到外力迫使它改变。

### 第二定律

$$\vec{F}_{合} = m\vec{a}$$

方向与加速度方向相同，是矢量式。

### 第三定律

作用力与反作用力大小相等、方向相反、作用在不同物体上。

---

## 3. 常见力

- 重力 $G = mg$
- 弹力（胡克定律 $F = kx$）
- 摩擦力（静摩擦与滑动摩擦 $f = \mu N$）

---

## 4. 处理问题的基本思路

1. 确定研究对象
2. 受力分析（画受力图）
3. 建立坐标系或正交分解
4. 列牛顿第二定律方程
5. 结合运动学公式求解
