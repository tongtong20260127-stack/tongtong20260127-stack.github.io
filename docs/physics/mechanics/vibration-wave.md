# 机械振动与机械波

## 1. 简谐运动

回复力满足 $F = -kx$ 的振动。

- 位移、速度、加速度随时间按正弦/余弦规律变化
- 周期 $T = 2\pi\sqrt{\dfrac{m}{k}}$（弹簧振子）
- 单摆周期 $T = 2\pi\sqrt{\dfrac{l}{g}}$（小角度）

### 能量

简谐运动中动能与势能相互转化，机械能守恒（理想情况）。

---

## 2. 机械波

机械振动在介质中的传播形成机械波。

- 横波与纵波
- 波长 $\lambda$、波速 $v$、频率 $f$ 关系：$v = \lambda f$
- 波的反射、折射、干涉、衍射

### 波的图像

$y$-$x$ 图像表示某一时刻介质中各质点的位移；注意与振动图像（$y$-$t$）的区别。
