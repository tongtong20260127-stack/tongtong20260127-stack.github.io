# 原子核与核反应

## 1. 原子核组成

质子与中子（核子）。质量数 $A$，电荷数 $Z$。

## 2. 放射性衰变

- $\alpha$ 衰变：$^A_Z X \rightarrow ^{A-4}_{Z-2} Y + ^4_2 He$
- $\beta$ 衰变：$^A_Z X \rightarrow ^A_{Z+1} Y + ^0_{-1} e$
- $\gamma$ 辐射：放出光子，核从激发态回到低能级

半衰期：放射性元素的原子核有半数发生衰变所需的时间。

## 3. 质能方程

$$E = mc^2$$

核反应中的质量亏损对应放出的能量。
